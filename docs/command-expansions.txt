GCU COMMAND NAME GLOSSARY
Version 0.2.0

Each entry gives the GNU behavioral reference (where applicable), Gill expansion, practical purpose, and usage. The Gill names are project-defined. An expansion is a naming aid, not a technical limitation on the implementation.

cowf
  GNU/reference: cat
  English expansion: Content Output and Write Files
  Purpose: Concatenate files and write their contents to stdout.
  Usage: cowf [-sa] [-num|-numb] [-she] [-T] [-v] [-squb] [FILE...]

fcow
  GNU/reference: tac
  English expansion: File Contents in Opposite Way
  Purpose: Write input records/lines in reverse order.
  Usage: fcow [-bef] [-rex] [-s SEPARATOR] [FILE...]

numl
  GNU/reference: nl
  English expansion: Number Lines
  Purpose: Number lines, with configurable numbering of sections.
  Usage: numl [OPTIONS] [FILE...]

  GNU/reference: od
  English expansion: Write Files in Other Formats
  Purpose: Display file data in selected numeric or character representations.
  Usage: wfof [OPTIONS] [FILE...]
